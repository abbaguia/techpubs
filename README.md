# TechPubs Repository 🚀

Welcome to **TechPubs**—the centralized repository for technical whitepapers, architecture guides, deep dives, and engineering blogs by **Mahamat Hissein GUIAGOUSSOU** (Developer Community Leader & Senior Cloud and AI Architect).

This repository serves as the canonical home and version-controlled source for technical content spanning distributed systems, cloud computing, Infrastructure as Code (IaC), and artificial intelligence infrastructure.

---

## 📂 Repository Structure

To keep navigation intuitive and avoid a deep, cumbersome folder tree, content is organized flatly into curated categories under the `/articles/` directory using descriptive file naming and metadata tags:

```text
TechPubs/
├── .github/              # Issue templates, CI/CD, and workflows
├── articles/             # Main directory containing all published technical notes & blogs
│   ├── general/          # Artificial Intelligence & AI Infrastructure deep dives
│   ├── iac/              # Terraform, OpenTofu, and Infrastructure as Code articles
│   ├── resilience/       # Systems resilience, architecture patterns, and SRE whitepapers
│   └── ai/               # General cloud architecture and developer community essays
├── assets/               # Shared images, diagrams, infographics, and banners
├── README.md             # Root repository documentation (You are here)
└── CONTRIBUTING.md       # Contribution guidelines and review standards
